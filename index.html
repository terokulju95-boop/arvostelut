Raahaa rivejä ⠿-kahvasta. Kategoria, alalaji ja arvostelutyyppi pysyvät aina ylimpänä, koska ne ratkaisevat mitkä muut kentät näkyvät.
Kategorian sisäinen jako, esimerkiksi Elokuvat → Perus / Dokumentit. Alalajivalitsin näkyy arvostelulistan yläpuolella vain niissä kategorioissa joilla on alalajeja.
Rajat vaikuttavat kaikkiin väreihin: korttien reunoihin, arvosanarenkaisiin, Top-listaan ja arvosanasuodattimeen. Jos käytät asteikon yläpäätä tiiviisti, nosta rajoja.
Kuinka paljon kukin ryhmä vaikuttaa laajennetun arvioinnin pisteeseen. 1,0 = normaali.
Montako kysymystä vertailu esittää enintään. Enemmän kysymyksiä = tarkempi piste.
Tunnuksen saa osoitteesta themoviedb.org → Settings → API → API Read Access Token. Se tallennetaan vain omaan pilveesi, ei koodiin.
Käy läpi kaikki elokuvat ja sarjat, kertoo miltä puuttuu julisteita, ohjaajia, kestoja tai tuotantotiloja, ja näyttää tarkalleen mitä muuttuisi ennen kuin mitään tallennetaan.
